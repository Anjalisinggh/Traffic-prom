# Traffic Navigator

A small single-page prototype for a route finder: enter a destination and it lists route options to get there.

## How it works

- Type a destination and press **Find Routes**.
- The page shows three suggested routes as cards.
- An empty destination shows a prompt to enter one.

The routes are sample data for now. The next step is to connect a maps API (e.g. Google Maps Directions) for real routes and live traffic.

## Tech Stack

Plain HTML, CSS and JavaScript in a single file (`traffic.html`). There's no build step and no dependencies.

## Run Locally

```bash
git clone https://github.com/Anjalisinggh/Traffic-prom.git
cd Traffic-prom
```

Then open `traffic.html` in your browser.
